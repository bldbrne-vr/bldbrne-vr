Beast Roar replacement, revision 18 art / revision 19 idle / revision 20 activation / optimized runtime v2

Original mesh, rig, albedo, normal and roughness maps authored for this mod.
No extracted Bloodborne mesh, texture, skeleton or animation is in this resource.
The separate local hunter-body placement previews use game data and are not shipped.

Source and exporter (kept with the project):
  original-beast-hand.three.json, preview.js, weathering.js, refine.js
  export-runtime.cjs -> runtime/export.json and material PNGs
  optimize-mesh.cjs -> runtime/optimized-export.json (offline meshoptimizer v0.25)
  pack-runtime.py -> this directory's beast_roar.brb

The export preserves the approved motion, thumb-heel weights and worn materials.
The root is fixed; the wrapped wrist attaches to the existing hunter grip.
16 bones, 5,430 vertices, 6,968 triangles, one indexed draw per visible instance.
Simplification retains original surviving vertices/UVs/colors/skin weights, pins the thumb heel,
and preserves borders. Indices and vertex order are optimized for the GPU vertex cache.
16-bit GPU indices; 32-bit indices in the validated CPU payload.
255 immutable palette frames, sampled at 30 Hz and interpolated on the GPU:
  0: stored/rest
  1..46: normal activation (1.5 s sampled motion, 1.65 s playback with 150 ms open hold)
  47..109: every fourth successful activation (2.05 s)
  110..254: staggered held finger extensions/tremor (4.8 s, eased loop seam)
Stored items use frame zero. Item use, movement and controller tracking are unchanged.

BRZ1 + little-endian u32 decompressed size + zlib payload (version 2).
Payload: 64-byte header; 32-byte position/normal/UV vertices; u32 triangle indices;
vec4 animation metadata (joint0/joint1/weight0/weight1, then colorRGB/normalStrength),
16 x 3 vec4 matrix rows per frame; albedo and surface BC3 mip chains.
Each atlas is 512 square, four 224-pixel tiles with 16-pixel wrapped gutters,
five mip levels. Surface stores tangent-space normal RGB and roughness alpha, sampled linear;
albedo is sampled sRGB. Compression and mip generation happen offline only.
Both mip chains together: 698,368 bytes. Mesh, indices, animation and textures: 1,283,536 GPU
payload bytes, excluding driver allocation granularity. Packed resource: 522,295 bytes.
The parser checks version, exact length, counts, indices, finite values, material tiles, bone
indices, weights, palette bounds and mip sizes before publication. Decompression is capped at
2 MiB; at most 8,192 vertices / 36,000 indices are accepted. Upload failures release partial
resources and are cached rather than retried every frame. GPU destruction is deferred until safe.
Stored copies skip palette interpolation; single-joint vertices skip the second joint fetch.
Animation descriptors share the existing draw descriptor command; no added descriptor command.
