# Bldbrne-VR 0.9.61

- **The launcher's start-up file is replaced.** On 18 November Windows Defender began to block it (as `Trojan:Win32/Yomal!rfn`) in every version from 0.9.3 to 0.9.6. That file is the packaging tool's own start-up stub and had not changed since 0.9.3; this version ships it as a new file that Defender passes.
- If Windows already removed the file and the launcher no longer starts, download the installer from this page and install again. Your settings and saves stay.
- Nothing else changes: the game is 0.9.6's.
